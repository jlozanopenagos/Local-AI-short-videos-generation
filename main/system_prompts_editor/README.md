# System Prompts Editor

This directory contains ready-to-copy system prompts for web AI interfaces (Gemini, Claude, ChatGPT) used in human-in-the-loop auditing and doctoring of LingoVerse scripts and image prompts.

## Available Prompts

- [`IMAGE_PROMPT_AUDITOR.md`](./IMAGE_PROMPT_AUDITOR.md): Audits, steers, and doctors ComfyUI Z-Image Turbo visual prompts (2D cartoon, character eyes, room depth, theme steering, zero text/interjections).
- [`EXPRESSION.md`](./EXPRESSION.md): Doctors 5-section Expression Short scripts (Hook, Setup, Discovery, Example, Payoff; 85-110 words).
- [`ROLEPLAY.md`](./ROLEPLAY.md): Doctors 6-scene Roleplay Short dialogues (Hook, Dialogue 1-4, Payoff; 145-180 words).
- [`GAME.md`](./GAME.md): Doctors interactive Game/Quiz Shorts (Hook, Challenge, Pressure, Answer, Explanation; 90-120 words).
- [`FUN_FACTS.md`](./FUN_FACTS.md): Doctors curious cultural/linguistic Fun Facts Shorts (Hook, Fact 1-3, Payoff; 95-135 words).

All prompts are also compiled in the canonical root file [`system_prompts_editor.csv`](../system_prompts_editor.csv).
