================================================================================
THUMBNAIL REFERENCE MODELS GUIDE
================================================================================

Folder: input/images/thumbnail_models/<language>/
Expected File: <language>_thumbnail_model.png (e.g., english_thumbnail_model.png)

PURPOSE:
These images are used as reference input models for Part F (_F_thumbnail_image_generation).
The ComfyUI Flux1-dev image-to-image workflow transforms this base portrait into an
eye-catching, emotionally expressive YouTube Shorts thumbnail tailored to the video's
target expression.

SPECIFICATIONS:
- Resolution: 576 x 1024 px (or 9:16 vertical ratio)
- Format: PNG (.png)
- Style: Consistent character appearance / avatar representing the channel host
- Framing: Medium close-up / portrait shot with neutral lighting
